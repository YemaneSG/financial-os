# Financial OS — Review Index

Reviews are immutable evidence about a specific artifact version. They do not silently edit the plan or decide product authority by majority vote.

## Current gate

- `gate-a-review-packet.md` — frozen plan-review instructions, evidence manifest, reviewer charters, and synthesis protocol
- `gate-a/` — location for the three independent reports, synthesis, and owner disposition once the gate runs

## Gate rule

Gate A passes only when:

1. all three independent reports are collected before synthesis;
2. every blocking and High finding has an evidence-backed disposition;
3. affected artifacts and hashes are updated when required;
4. reviewers re-evaluate materially changed conclusions;
5. each reviewer signs `Approve` or `Approve with conditions`, with no condition that blocks implementation;
6. the owner authorizes implementation and external cloud/repository access.

Agent agreement is not evidence. Findings are evaluated individually against requirements, authoritative documentation, repository artifacts, tests, measurements, or explicit reasoning.
